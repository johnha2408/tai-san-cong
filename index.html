# Tổ dân phố Địa điểm bố trí Trạng thái Ngày BB Hồ sơ

Bật chế độ quản trị

Khi bật, ảnh và thông tin bạn cập nhật sẽ lưu thẳng vào repo GitHub, mọi người mở web đều thấy (sau khoảng 1 phút). Mỗi máy chỉ cần làm một lần.

  1. Mở trang tạo token GitHub (Fine-grained token).
  2. Repository access: chọn Only select repositories → chọn repo của trang này.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Bấm Generate token, sao chép và dán vào ô Token bên dưới.
Token chỉ lưu trên trình duyệt của máy này, không nằm trong trang web. Không bật trên máy dùng chung.
